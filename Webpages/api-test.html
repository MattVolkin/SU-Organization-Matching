GET

/api/officer/orgs — Officer's clubs

Returns the clubs managed by the authenticated officer.

PATCH

/api/officer/orgs — Update own club

Partially updates a club the officer manages. Only include fields that should change. id is required.

GET

/api/admin/orgs — All clubs (admin)

Returns every club. Requires admin role.

POST

/api/admin/orgs — Create club (admin)

clubName is required. Officer emails in officers must belong to existing users.

PATCH

/api/admin/orgs — Update club (admin)

Partially updates any club. id is required. Only include fields that should change.

DELETE

/api/admin/orgs — Delete club (admin)

Permanently deletes a club by id. This cannot be undone.
